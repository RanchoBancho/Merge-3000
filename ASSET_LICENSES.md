# Asset provenance

The current prototype contains no third-party visual or audio assets.

| Asset | Source | License / note |
| --- | --- | --- |
| Merge object sprites | Generated at runtime by project code | Original project code |
| Particles and backgrounds | Generated at runtime by project code | Original project code |
| Sound effects | Synthesized at runtime by project code | Original project code |
| UI font | User device system font stack | Not bundled or redistributed |
| App icon | Project SVG | Original project code |

Any future external or generated production asset must be added here with its source, author, license, purchase record, and allowed platforms before it enters a release build.
